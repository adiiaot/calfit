Calories remaining = goal − eaten. Steps → kcal at a fixed rate. Fasting timer derives from the stored start time. Streak grows by one per check-in day.

Architecture — three lines

  1. Phone: React Native + Expo — one codebase → Android, iOS, web. Zustand state, session in secure storage.
  2. Data: Supabase — Postgres, Auth, Realtime chat, Storage. RLS: user_id = auth.uid() on every user table.
  3. AI: phone → Edge Function ai-proxy → NVIDIA. Key lives in Supabase secrets, never in the app.

The four answers they will actually ask

QuestionAnswer — say it in this shape
What problem?People quit because progress is invisible: scattered records, food they cannot log, generic plans, no accountability.
You vs AI tools?We defined the requirements, chose the architecture, reviewed and tested every change. AI drafted and debugged faster. If it broke, it was our call.
How did you test?Three layers: read the code, 32 automated checks after every fix, written device test list. Nothing counts as passed until it runs on a phone.
What is unfinished?AI proxy still accepts unauthenticated calls, account deletion is not finished server-side, long-history charts need a redesign, device testing incomplete — all in KNOWN_ISSUES.md.

Backups: why Expo · where data lives · offline behaviour (message, never a crash) · what happens when the AI model is retired (config + fallback workout).

Demo path — 5 steps, ~2 min

  1. Home — calories, water, steps, sleep, streak.
  2. Calorie — search eba, log it, watch the number drop.
  3. AI Coach — generate a short workout.
  4. Activity — start it: voice cue, timer, auto-advance.
  5. Progress — week view, then export.

60 seconds only? 1 → 2 → 3, then: “the rest is in the deck.”

If something goes wrong

  • Wi-Fi dies: deployed web build → screen recording → screenshots. Keep talking; never debug on stage.
  • AI is slow: narrate what should happen; cache is 5 minutes, try once more.
  • Forgot a number: “I will come back to that” — and come back. Never guess.
  • Scope challenge: “It runs today; it is not a store product yet, and the report says exactly what is missing.”
